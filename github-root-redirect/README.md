# Root GitHub Pages Redirect

Use these files in the repository `SerZhyAle.github.io` to make `http://serzhyale.github.io/` open the main portfolio immediately.

## What to publish

- `index.html`

## Target

- `http://sza.od.ua/`

## Notes

- The current repository `sza.od.ua` cannot by itself control the root GitHub Pages address `serzhyale.github.io`.
- The root address is handled by a separate user-site repository named `SerZhyAle.github.io`.
