## Как собрать это в Google Sites

### Рекомендуемый layout

1. Hero section на всю ширину
2. Блок кнопок сразу под intro
3. Одна крупная карточка для `ELTR`
4. Секция `GitHub Projects` в сетке `2 x 3`
5. Последний компактный блок с контактами

### Какой тип изображений использовать

- Если блок в Google Sites широкий: используй `preview.png`
- Если карточка квадратная или узкая: используй `icon.png`
- Для `FastMediaSorter_mob_v2` лучше оставить скриншот интерфейса, он смотрится сильнее обычной иконки

### Порядок публикации

1. Открыть сайт в редакторе Google Sites
2. Заменить текущий текст визитки на секции из этого файла
3. Вставить блок `Проекты 1С`
4. Добавить секцию `GitHub Projects`
5. Для каждой карточки загрузить соответствующее локальное изображение
6. Для каждой карточки добавить кнопку `Репозиторий`
7. Проверить мобильную версию
8. Опубликовать обновление
