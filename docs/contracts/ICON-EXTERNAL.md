# ICON-EXTERNAL

- **Id:** `ICON-EXTERNAL`
- **Version:** 0.9
- **Home:** the shared contracts catalog, `iconography/README.md` - see [CLAUDE.md](../../CLAUDE.md) for where the catalog is
- **Role:** consumer. This hub displays project identity artwork without turning it into control glyphs.

## What this repo must do to stay conformant

- Preserve an external owner's mark as supplied; do not recolour or redraw it as a look-alike.
- Treat downloaded pictures and project marks as content or identity artwork, never as action icons.
- Provide a vocabulary glyph fallback if a future external image represents a functional content type and fails to load.
